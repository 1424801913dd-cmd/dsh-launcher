# DSH Launcher 用户指南

> 适用版本：源码 `0.4.1` 及后续兼容版本
> 项目性质：非官方、独立维护，未获得 DeepSeek 或 DSH 上游背书

## 首次使用

首次打开启动器后，按界面的三个步骤操作：

1. **检查环境**：确认 Windows、x64、WebView2 和可用磁盘空间均显示通过。推荐普通用户保留默认目录；如需修改，可展开“安装与数据目录”，保存后启动器会重启。
2. **下载并验证**：等待版本查询成功，选择“推荐版”并确认按钮上的精确版本后开始安装。查询前或查询失败时不能安装；标签变化时会停止并要求重新查询、确认。启动器会从 `nodejs.org` 和 npm 官方 registry 下载内容，并验证 Node.js SHA-256、npm integrity、实际包/CLI 版本、原生模块以及 DSH 的隔离启动/停止结果。
3. **启动 DSH**：安装完成后点击“启动 DSH 并完成检查”。健康检查通过后再打开 Web 界面。

Alpha 是主动选择的预览通道，可能不稳定，不会静默安装，同样锁定用户确认的精确版本。首次安装失败不会覆盖已经存在的活动 Runtime；检查网络、重新查询并确认目标后再点击“重试安装”。0.4.1 不会自动删除或修正旧版已装入的 Runtime。

## 目录与数据

全新安装的默认目录为：

| 内容 | 默认位置 |
| --- | --- |
| Runtime 与版本记录 | `%LOCALAPPDATA%\DSH Launcher\runtime` |
| 下载与 npm 缓存、日志 | `%LOCALAPPDATA%\DSH Launcher\cache` |
| DSH 用户数据 | `%LOCALAPPDATA%\DeepSeek Harness\home` |
| 工作区 | `%USERPROFILE%\Documents\DSH Workspace` |

路径只能在首次安装前修改。保存路径会创建目标目录并重启启动器，但不会搬移或删除已有文件。已经安装 Runtime 后，启动器会锁定这些设置，以避免活动版本或用户数据意外失联。

早期版本的有效 D 盘安装会继续原位使用。版本切换、回滚和卸载启动器均不应自动删除 `DSH_HOME`。

## 日常使用

- “启动 DSH”会启动由本启动器监督的后台进程；健康检查完成后“打开 DSH 界面”才可用。
- 关闭主窗口只会隐藏到系统托盘，不会停止 DSH。
- “停止 DSH”会先尝试安全退出，超时后才清理受管进程树。
- 版本管理采用旁路安装；新版本通过验证后才允许切换，上一版本可用于回滚。
- 断网不会影响已经安装的 Runtime 启动，只会影响版本检查、首次安装或更新下载。

## 常见问题

### 无法查询版本或下载超时

确认浏览器可以访问 `https://registry.npmjs.org/` 和 `https://nodejs.org/`，并检查系统代理、防火墙或安全软件。恢复网络后先点击版本查询/刷新按钮，核对新显示的精确版本，再重试安装。不需要删除缓存或现有 Runtime。

### npm 安装未完成

先检查 npm 官方 registry 可访问、磁盘空间不少于 3 GB、目标目录可写。再次安装时，启动器会复用已通过校验的下载缓存，并重新建立隔离 staging；活动 Runtime 不会被覆盖。

### 无法启动或页面打不开

先查看状态提示。若提示 3080 端口存在外部服务，启动器不会接管或结束该进程；请先关闭占用端口的软件。若 Runtime 启动验证失败且存在上一版本，可在版本管理中回滚。

### 获取诊断信息

在“启动器日志”区域选择：

- **复制诊断摘要**：复制启动器、Windows、WebView2、Runtime 状态和最近错误；当前用户路径会替换为 `%USERPROFILE%` 或 `%LOCALAPPDATA%`，凭据类内容会脱敏。
- **打开日志目录**：在文件资源管理器中打开持久日志。提交问题前仍应人工检查内容，不要发送 API Key、令牌、Cookie 或完整会话。

## 当前发布限制

SignPath Foundation 申请目前未获批准，公开制品不能声称已获得 Foundation 证书或其背书。没有有效 Authenticode 签名时，Windows 可能显示未知发布者或 SmartScreen 提示。
正式发行制品只从项目发布页获取；受邀试用者可使用维护者明确提供、对应已核验 CI 记录的候选包，并核对另行确认的 SHA-256。两者不能混称。受控试用流程见 `TRIAL_GUIDE.md`（试用 ZIP 中为 `READ-ME-FIRST.md`）；系统阻止或来源不明时停止，不要求关闭安全防护。
