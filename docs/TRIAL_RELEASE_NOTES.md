# DSH Launcher 0.4.1 版本漂移修复候选

> 0.4.0 旧候选在 Windows 10 实体机发现安装版本与界面确认版本不一致，已停止作为新一轮测试入口。旧包及测试现场保留用于追溯。0.4.1 的桌面复测尚未完成。

候选编号：`0.4.1-trial-ci33857469193`；启动器版本 `0.4.1`。本编号标识受控测试包，不代表正式稳定 Release。

## 本轮变化

- 移除未经查询的硬编码推荐/Alpha 版本，未知或查询失败时禁止安装。
- 点击时锁定精确版本，后端核对成功查询的快照和最新标签；变化时停止并要求重新确认，不静默换目标。
- 校验精确 manifest、实际包/CLI、Runtime 记录和首次激活版本，失败不覆盖现有活动指针。
- 增加两通道标签漂移、缺失、503、manifest/记录错误及激活保护回归。
- 补充静默/带进度界面安装后的卸载注册表验证、只读诊断脚本及测试端旧现场保留流程。
- 不自动删除、降级或修正旧候选已经装入的 Runtime；原有默认目录、隔离安装及更新关闭边界保持。

## 已知限制

- 安装器未签名；SignPath Foundation 未批准申请，不声称已签名或获得任何官方背书。
- 这是联网安装型启动器，ZIP 不包含 Node/DSH Runtime；首次安装需要访问官方 Node/npm 源，可能受网络、代理或安全软件影响。
- 远程更新未启用；后续测试版本由维护者明确提供，不会自动切换到未知制品。
- 已安装 Runtime 后不支持直接迁移目录；需要另行设计迁移和恢复流程。
- 上游仍为 developer preview；打开 DSH 页面不代表 API 配置、模型请求及所有上游功能已经验收。
- 只使用测试数据。现阶段不建议将此包作为重要工作流的唯一运行环境。
